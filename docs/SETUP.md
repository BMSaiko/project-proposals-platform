# Setup — Project Proposals Platform (DSOS)

> Documentation added in 2026 (portfolio). Derived from the source code, `composer.json` and the migrations. **No command below was run**: this machine has no PHP, Composer or MySQL set up for the project (marked `not tested`). Portuguese version: [SETUP.pt.md](SETUP.pt.md).

## Prerequisites

| Item | Version | Source |
|---|---|---|
| PHP | 8.1 or newer, with the usual Laravel extensions (`mbstring`, `openssl`, `pdo_mysql`, `fileinfo`, `xml`, `ctype`, `tokenizer`) | `composer.json` |
| Composer | 2.x | `composer.lock` |
| MySQL / MariaDB | any version supporting `utf8mb4` | `database/migrations/` |
| Node.js | not needed to run: the Blade views use the prebuilt assets in `public/assets` and `package.json` has no scripts | `package.json` |

## Environment variables

Set in the `.env` file you create in step 2 (the repository ships only `.env.example`; never commit `.env`).

| Variable | Meaning |
|---|---|
| `APP_KEY` | Generated by `php artisan key:generate` |
| `APP_URL` | Base URL, for example `http://127.0.0.1:8000` |
| `DB_CONNECTION` | `mysql` |
| `DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD` | Your own MySQL instance and credentials |
| `MAIL_MAILER`, `MAIL_HOST`, `MAIL_PORT`, `MAIL_FROM_ADDRESS` | Used by the password-reset e-mail; use `MAIL_MAILER=log` to read the reset link in `storage/logs/laravel.log` |

`.env.example` points to the course's MySQL server; replace those values with your own instead of using them.

## Steps

All commands are run from `project-proposals-platform/DSOS-grupo1-Bombastico/` (not tested).

1. **Install PHP dependencies**
   ```
   composer install
   ```
   `minimum-stability` is `dev`, so resolution may pick pre-release packages; `composer.lock` is committed, use it.
2. **Create the environment file**
   - PowerShell: `Copy-Item .env.example .env`
   - bash: `cp .env.example .env`

   Then edit `.env` with your database settings and `php artisan key:generate`.
3. **Create the database and run the migrations**
   ```
   mysql -u <user> -p -e "CREATE DATABASE dsos CHARACTER SET utf8mb4;"
   php artisan migrate
   ```
   Set `DB_DATABASE=dsos` in `.env`.
   - Caveat: the migrations do not match the original schema the code expects (column `Tipo de Trabalho` instead of `Tipo_de_Trabalho`; no `rel_proposta_aluno_pdf` table) and there are no seeders, so the application will not behave correctly. The original SQL dump was removed from the repository because it held personal data. See [ARCHITECTURE](ARCHITECTURE.md#data-model).
4. **Public storage link** (uploaded files; not tested): `php artisan storage:link`
5. **Run**
   ```
   php artisan serve
   ```
   Open `http://127.0.0.1:8000/` (login page).

## Accounts

- Companies can self-register at `/registar` and must be approved by an admin before they are marked `aprovada`.
- Students are created by an admin through the CSV import (`POST /aluno/upload`, 12 columns: name, birth date, e-mail, NIF, country, city, info, phone, image, username, password, class). Because the importer stores the password unhashed (known issue #3), set the password with a bcrypt hash in the CSV or fix it in the database.
- There is no screen to create admins or teachers. Insert rows in `acesso`, `dados_pessoais` and `admin` / `docentes` by hand; get a hash with `php artisan tinker` → `bcrypt('<password>')`.
- Never commit database dumps with real data.

## Tests

`php artisan test` runs `tests/Feature` (Laravel example tests plus the Breeze-style `Auth` and `ProfileTest`) and `tests/Unit/ExampleTest.php`. They were not run; the authentication tests are written for the default Laravel scaffolding and are not expected to match the custom `Login` controller. There is no CI.

## Troubleshooting

| Symptom | Likely cause | Fix |
|---|---|---|
| `No application encryption key has been specified` | Missing `APP_KEY` | `php artisan key:generate` |
| `SQLSTATE[HY000] [2002]` / `[1045]` | Wrong host or credentials; `.env` still points to the course server | Fix `DB_*` in `.env`, then `php artisan config:clear` |
| `Base table or view not found: rel_proposta_aluno_pdf` | That table is not in the migrations | Only affects PDF applications; known issue |
| `Unknown column 'Tipo_de_Trabalho'` | Schema built from the migrations, which differ from the original schema | Rename the column in `propostas` to `Tipo_de_Trabalho` (not tested) |
| Errors when listing or caching routes (`php artisan route:list`, `route:cache`) | Old-style string routes at the bottom of `routes/web.php` | Known issue #8; the named routes in the `site.` group are the working ones |
| No reset e-mail arrives | `MAIL_HOST=mailpit` has no server | Run Mailpit or use `MAIL_MAILER=log` |
| Uploaded files give 404 | Missing public link | `php artisan storage:link` |
| 419 Page Expired on POST | Session or CSRF cookie lost | Clear cookies, `php artisan config:clear` |

## Security notes

- Never commit `.env`; rotate any credential that has been committed (see [ARCHITECTURE](ARCHITECTURE.md#known-issues-verified-in-the-code-not-fixed) #7).
- Keep `APP_DEBUG=false` outside local use.
- Sanitise any database export before sharing a copy.
